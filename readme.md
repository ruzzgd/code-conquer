# 🎮 My First Godot Game

> First completed game made with Godot Engine 4.  
> Built to learn game development, scripting, and project organization. Now focusing on web & mobile development, but this project represents practical experience in programming.

---

## 🚀 About
A 2D top-down game where the player explores a lab, defeats robots, solves coding-based challenges, and collects cores to unlock the exit.

## ✨ Features
- Top-down player movement  
- Shooting & combat system  
- Enemy AI (drones / robots)  
- Doors, terminals, chests, and elevators  
- Debug challenge system (if-else logic puzzles)  
- Boss fights and multiple floors/maps  
- Pixel art + basic animations
